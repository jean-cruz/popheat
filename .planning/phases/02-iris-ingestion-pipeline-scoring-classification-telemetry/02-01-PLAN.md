## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `data/venues.json` -> ScoreClassifyProcess | Catalog data (OSM-sourced venue names/categories) crosses into scoring/SQL-building logic |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering / Injection | PersistOperation's `iris.sql.exec` INSERT calls | high | mitigate | Exclusively use `?`-parameterized `iris.sql.exec(sql, *params)` for every venue-derived field (name, category); never build the SQL string via f-string/`.format()`/concatenation -- enforced by Task 2's acceptance_criteria grep. |
