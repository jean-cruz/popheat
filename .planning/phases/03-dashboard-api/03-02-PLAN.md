<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public internet -> PopHeat.API (%CSP.REST) | Untrusted client GET requests reach /csp/popheat/api/{venues,counts,telemetry,status}; unauthenticated by design (D-06) |
| Public internet -> dashboard.html (static CSP page) | Untrusted clients load and execute the page's HTML/JS in their own browser |
| PopHeat.API -> PopHeat.Reading / PopHeat.BatchTelemetry | Read-only embedded SQL queries against Phase 2's persisted data; the API never writes |
| dashboard.html -> CDN (e.g. unpkg.com) | The browser loads Leaflet/Leaflet.heat JS/CSS from a third-party CDN at runtime |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|------------------|
| T-03-01 | Tampering | PopHeat.API GET routes | high | mitigate | All four routes accept zero user-supplied query/path parameters; every SQL statement is a fixed, parameterless %SQLQuery/embedded-SQL string, closing off SQL injection entirely (see Plan 03-01) |
| T-03-02 | Information Disclosure | PopHeat.API Status() method | medium | mitigate | IsProductionRunning wrapped in Try/Catch, degrades to {"running": false} rather than leaking an error/stack trace (see Plan 03-01) |
| T-03-03 | Denial of Service | PopHeat.API (all routes), unauthenticated + unrate-limited | low | accept | Single-container demo deployment for a judged contest window; rate limiting out of scope for the one-day timeline (see Plan 03-01) |
| T-03-04 | Elevation of Privilege | /csp/popheat/api and /csp/popheat (both AutheEnabled=64, unauthenticated) | low | accept | Deliberate per D-06/UI-SPEC: public, read-only, no PII, no write operations, no secrets |
| T-03-05 | Tampering | PopHeat.API SQL statements | high | mitigate | SELECT-only, no INSERT/UPDATE/DELETE anywhere in PopHeat.API.cls (see Plan 03-01) |
| T-03-06 | Tampering | dashboard.html's CDN-loaded Leaflet/Leaflet.heat script/link tags | medium | mitigate | This plan's Task 1 pins Subresource Integrity (integrity= plus crossorigin="anonymous") on every CDN script/link tag, including the new Leaflet.heat plugin tag, so a compromised or MITM'd CDN response is rejected by the browser |

</threat_model>
