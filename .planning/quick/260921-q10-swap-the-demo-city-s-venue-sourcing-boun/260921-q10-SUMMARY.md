## User Setup Required

**One manual step remains**, to be run from a terminal with docker access (where the container actually lives):

```bash
cd /home/jean/git/popheat

# 1. Purge PopHeat.Reading so no stale Porto venue lingers as a "latest" reading
#    (never runs `docker compose down` — only exec against the already-running container)
docker compose exec -T iris iris session IRIS -U POPHEAT <<'EOF'
set sc = ##class(PopHeat.Reading).%DeleteExtent()
if 'sc { do $System.Status.DisplayError(sc) }
halt
EOF

# 2. Wait ~8s (poller runs every 3s) then verify live data reflects only São Paulo
sleep 8
curl -s http://localhost:52773/csp/popheat/api/venues | python3 -c "import json,sys; v=json.load(sys.stdin); print(len(v), 'venues'); print('all in bbox:', all(-23.575<=x['lat']<=-23.545 and -46.675<=x['lon']<=-46.635 for x in v))"
curl -s http://localhost:52773/csp/popheat/api/counts
```

Then reload `http://localhost:52773/csp/popheat/dashboard.html` — the map should open already centered on São Paulo with only São Paulo venues.
